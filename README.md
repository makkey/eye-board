# EyeBoard

目を「スティック」のように大きく動かして、12キー配列でひらがなを入力するウェブアプリの MVP です。

一般的な視線入力は「画面のどこを見ているか」を推定しますが、小さな画面では目の動きが小さく、普通のカメラでは精度が出にくいという課題があります。EyeBoard は画面から視線を外すくらい大きく目を動かしてもらい、**「中央・上・右上…」の6方向と「目を閉じる」だけ**を判定します。画面を見ていない間は音声と効果音で状態を伝えます。

## 操作

カメラから見ると「下を見る」と「目を閉じる」はほぼ同じに写り区別できないため、**下方向は使わず「目を閉じる（下を見る）」を1つの操作**として扱います。使う方向は ↖ ↑ ↗ ← → の5つです。

| 1段目（行を選ぶ） | 短く | 長く（2秒） |
|---|---|---|
| ↖ | あ | ま |
| ↑ | か | や |
| ↗ | さ | ら |
| ← | た | 編集（続けて ← で削除） |
| → | は | わ |
| 目を閉じる／下を見る | な（0.6秒） | 記号（そのまま2秒） |

1. 方向を約0.6秒見る → 明るい上昇音と行名の読み上げ → **画面に視線を戻す**と確定。2秒見続けると低い下降音とともに長い方の行に切り替わる
2. 目を閉じる（下を見る）と、0.6秒で「な行」、そのまま2秒で「記号」。閉じている間に決まるので、読み上げを聞いてから開ければよい
3. 2段目は**フラワー配置**（ATOK のフラワータッチと同じく、左から時計回り）：← あ段、↖ い段、↑ う段、↗ え段、→ お段。見て戻ると確定
4. 何も選ばずに戻る：2段目で**目を閉じる（下を見る）**。5秒何もしなくても戻る

特殊な行（← ↖ ↑ ↗ → の順）:

- **わ**: わ、を、ん、ー
- **記号**: 、 。 ゛゜小（直前の文字を は→ば→ぱ→は のように切り替え） ？ ！
- **編集**: 削除、空白、読み上げ、元に戻す、全消去（「← を2秒、続けて ←」で削除）

### 日本語・母音入力（AI 変換）

画面右上の「言語」を押すと 日本語（12キー）→ 日本語（母音入力）→ 英語 の順に切り替わります（設定の「日本語の入力方式」でも選べます）。母音入力では、各拍の**母音だけ**を入れ、文節ごとに AI が漢字かな交じりに変換します。12キーでは1文字に視線2回が要りますが、こちらは**1拍が視線1回**です。

| 操作 | 短く | 長く（2秒） |
|---|---|---|
| ← | あ | 編集（続けて ← で1拍削除） |
| ↖ | い | ん |
| ↑ | う | |
| ↗ | え | |
| → | お | 文節の区切り（未確定のまま次の文節へ） |
| 目を閉じる／下を見る | 変換（0.6秒） | 記号（、。？！改行） |

- っ は次の音の母音、ー は前の音の母音で入れる（とって → お・え・え、かーてん → あ・あ・え・ん）
- 1文節（「昨日は」など）入れて目を閉じると、それまでに確定した文を文脈として AI に送り、候補を最大5つ ← ↖ ↑ ↗ → に並べる（1番目が ←）。見て戻ると確定。どれも違う時は目を閉じると、それまでに見せた候補を除いて別の候補を聞き直す（「生卵が」のように文頭で出にくい言葉向け）。2秒閉じ続けると入力にもどる（入れた母音は残る）
- 区切りは文節ごと（「ね」を挟んで自然に切れるところ、主に助詞の後ろ）。例：昨日は｜楽しかったね｜ありがとう。AI にも「1区切り＝ちょうど1文節」と指示し（指示文 v3）、区切り位置まで入力と合う候補を先に並べる
- → を2秒で文節の区切りを入れ、2文節以上をまとめて変換することもできる。後ろの文節が手がかりになるので、文脈の無い文頭の言葉（「生卵が 食べたい」の「生卵が」など）が当たりやすくなる
- 母音が入力と合わない候補は表示しない
- 設定で AI の会社・モデル・API キー・考える深さ・同時に聞く回数を選ぶ。既定は母音ラボの測定で釣り合いの良かった Gemini 3.8 flash（考える深さ low・1回）。API キーはこのブラウザの中だけに保存し（母音ラボと共通）、選んだ会社の API に直接送る

### 英語

画面右上の「言語」で日本語と英語を切り替えます。5文字ずつアルファベット順に並べ、**a〜y は短い操作だけで、スペースは目を閉じるだけで**入ります（電話機式の ABC/DEF だと8グループ必要で、一部が2秒待ちの側に回るため）。この方式ではどのグループ・どの位置も手間が同じなので、使用頻度順に並べても速くならず、覚えやすいアルファベット順にしています。

| 1段目 | 短く | 長く（2秒） |
|---|---|---|
| ↖ | A B C D E | 1–5 |
| ↑ | F G H I J | 6–0 |
| ↗ | K L M N O | ! - : ; " |
| ← | P Q R S T | 編集（削除・Aa・読み上げ・元に戻す・Clear） |
| → | U V W X Y | ( ) / @ & |
| 目を閉じる／下を見る | スペース（0.6秒でその場で入力） | . , ? ' Z（そのまま2秒。入れたスペースは取り消す） |

- 2段目は日本語と同じく左から時計回り（A〜E なら ←A ↖B ↑C ↗D →E）
- 文頭の英字と、単独の「i」は自動で大文字。「Aa」で直前の文字の大文字・小文字を切り替え
- Backspace は「← を2秒、続けて ←」
- 読み上げは英語の声

画面のキーは 3×3 の正方形で並べています（横長だと斜めを見る時に視線が横に引っ張られるため）。中央は「見ても何も起きない」ことが分かるよう空けておき、目を閉じる（下を見る）操作は3段目の中央に置いています。

カメラなしでも、キーボードで流れを試せます（`Q W E / A D` または矢印キーで方向、`Space`・`X`・`↓` で目を閉じる）。

## 母音入力ラボ（実験）

`lab.html`（公開先では https://makkey.github.io/eye-board/lab.html ）は、日本語を**母音だけ＋文節の区切りの空白**で入力し（例：「昨日は 楽しかったね ありがとう」→「いおうあ あおいあっあえ あいあおう」）、LLM に元の文を推測させる方式の実験ページです。

- Claude / Gemini / ChatGPT / Sarashina を切り替え、API から取得したモデル一覧で比較できる
- API キーはブラウザの中だけに保存され、各社の API に直接送られる
- Sarashina の API はブラウザから直接呼べない（サーバー側から呼ぶ前提）ため、手元の PC で `node tools/cors-proxy.mjs`（Node.js 18 以上、依存なし）を動かし、その中継（http://127.0.0.1:8787）経由で送る
- 例文（`src/lab/dataset.ts`、編集可）を「文単位」または「文節ごと（前の文節は確定済みとして次を推測）」で推測させ、正解が1位・5位以内に入った割合、母音が入力と合う候補の割合、時間を集計する
- 指示文は v1（規則のみ・5候補）、v3（v2 に「1区切り＝ちょうど1文節」の決まりを加え、区切り位置まで合う候補を先にする。本体の母音入力はこれを使う）と v2（例・自己確認つきで10候補を出させ、母音が合うものを上位に並べ替えて先頭5つで採点）を切り替えて比べられる。実際に送る内容はページ上で確認できる
- っ・ー を専用のキーで入れる方式と、ローマ字入力のように っ は次の音の母音・ー は前の音の母音で入れる方式（とって→おええ、かーてん→ああえん）を切り替えて比べられる
- 返答は毎回少しずつ違うため、同じ問いを2〜3回同時に聞き、候補の順位を合算することもできる（待ち時間はほぼ同じ、料金は回数倍）
- 結果はテキストでコピーできる

## 仕組み

- [MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker) で顔のランドマークと blendshape を取得（すべて端末内で処理）
- 特徴量: blendshape の `eyeLook*`（上下左右）と `eyeBlink*`、目頭・目尻を基準にした虹彩位置、目の開き（上下まぶたの距離）
- キャリブレーションで中央・5方向・「目を閉じる」「下を見る」のサンプルを集め（下を見たサンプルも「閉じる」として記録）、クラスごとの代表値（中央値）とばらつきから最近傍で分類（ヒステリシス付き）
- キャリブレーション後、各クラスを正しく判定できた割合をデバッグ表示で確認できる（結果はテキストでコピーできる）
- 「閉じる」との切り替えにはヒステリシスを掛けない（瞬間的な揺れはエンジンのデバウンスで吸収）。判定の寄り具合は設定の「閉じた判定の広さ」で調整できる
- 状態機械（`src/engine.ts`）が方向の時系列を行選択・文字選択に変換

| ファイル | 役割 |
|---|---|
| `src/tracker.ts` | カメラと MediaPipe、特徴量の抽出 |
| `src/classifier.ts` | キャリブレーションの作成と方向の分類 |
| `src/calibration.ts` | 音声案内付きのキャリブレーション手順 |
| `src/engine.ts` | 入力の状態機械 |
| `src/layout.ts` | 言語ごとのキー配置 |
| `src/kana.ts` / `src/english.ts` | 濁点・小文字などの変換、英語の自動大文字 |
| `src/main.ts` | UI |
| `src/vowelime.ts` | 母音入力の変換（文節と文脈を AI に送り、候補を絞る） |
| `src/lab/` | 母音入力ラボ（母音への変換、LLM への指示と採点、各社 API の呼び出し） |
| `tools/cors-proxy.mjs` | ラボから Sarashina API を呼ぶための手元用の中継 |

## 開発

```sh
npm install
npm run dev      # http://localhost:5173
npm test
npm run build
```

カメラは HTTPS か localhost でのみ使えます。顔認識モデルは初回に Google のサーバーから読み込みます。

## デプロイ

`main` に push すると GitHub Actions で GitHub Pages に公開されます（リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください）。

## 調整のヒント

- **設定**から各時間・平滑化・中央の広さなどを変更できます
- **デバッグ**で特徴量の動き、各方向への距離、まばたき値を確認できます
- 判定が不安定な場合は、明るさ・カメラの高さを変えて再キャリブレーションしてください
