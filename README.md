# EyeBoard

目を「スティック」のように大きく動かして文字を入力するウェブアプリの MVP です。日本語は12キー配列のひらがな入力と、母音だけを入れて AI に漢字かな交じりへ変換させる母音入力、英語はアルファベット入力に対応しています。

一般的な視線入力は「画面のどこを見ているか」を推定しますが、小さな画面では目の動きが小さく、普通のカメラでは精度が出にくいという課題があります。EyeBoard は画面から視線を外すくらい大きく目を動かしてもらい、**「中央・上・右上…」の6方向と「目を閉じる」だけ**を判定します。画面を見ていない間は音声と効果音で状態を伝えます。

## 操作

カメラから見ると「下を見る」と「目を閉じる」はほぼ同じに写り区別できないため、**下方向は使わず「目を閉じる（下を見る）」を1つの操作**として扱います。使う方向は ↖ ↑ ↗ ← → の5つです。

| 1段目（行を選ぶ） | 短く | 長く（2秒） |
|---|---|---|
| ↖ | あ | ま |
| ↑ | か | や |
| ↗ | さ | ら |
| ← | た | 編集（続けて ← で削除） |
| → | は | わ |
| 目を閉じる／下を見る | な（0.6秒） | 記号（そのまま2秒） |

1. 方向を約0.6秒見る → 明るい上昇音と行名の読み上げ → **画面に視線を戻す**と確定。2秒見続けると低い下降音とともに長い方の行に切り替わる
2. 目を閉じる（下を見る）と、0.6秒で「な行」、そのまま2秒で「記号」。閉じている間に決まるので、読み上げを聞いてから開ければよい
3. 2段目は**フラワー配置**（ATOK のフラワータッチと同じく、左から時計回り）：← あ段、↖ い段、↑ う段、↗ え段、→ お段。見て戻ると確定
4. 何も選ばずに戻る：2段目で**目を閉じる（下を見る）**。5秒何もしなくても戻る

特殊な行（← ↖ ↑ ↗ → の順）:

- **わ**: わ、を、ん、ー
- **記号**: 、 。 ゛゜小（直前の文字を は→ば→ぱ→は のように切り替え） ？ ！
- **編集**: 削除、空白、読み上げ、元に戻す、全消去（「← を2秒、続けて ←」で削除）

### 日本語・母音入力（AI 変換）

画面右上の「言語」を押すと 日本語（12キー）→ 日本語（母音入力）→ 英語 の順に切り替わります（設定の「日本語の入力方式」でも選べます）。母音入力では、各拍の**母音だけ**を入れ、文節ごとに AI が漢字かな交じりに変換します。12キーでは1文字に視線2回が要りますが、こちらは**1拍が視線1回**です。

| 操作 | 短く | 長く（2秒） |
|---|---|---|
| ← | あ | 編集（続けて ← で1拍削除） |
| ↖ | い | ん |
| ↑ | う | 小さい っ |
| ↗ | え | |
| → | お | 文節の区切り（未確定のまま次の文節へ） |
| 目を閉じる／下を見る | 変換（0.6秒） | 記号（、。？！改行） |

- 小さい っ は ↑ を2秒、ー は前の音の母音で入れる（とって → お・っ・え、かーてん → あ・あ・え・ん）。以前は っ も次の音の母音で入れていたが、利用者が考える負担が大きかったため専用にした。AI にも「っ はそのまま入力される」と伝える
- 文頭の文節の**最初の1文字だけ**は12キー（行 → 文字）で入れ、2文字目から母音だけにする（「生卵が」なら な・あ・あ・あ・お・あ）。最初の拍が分かると候補がぐっと絞れる（文頭は文脈が無く、母音だけでは「生卵」のような言葉がなかなか出ないため）。AI には「な行で始まる」と伝え、その行で始まらない候補は捨てる。濁点・半濁点・小さい字は区別しないので、か を選べば が・きょ も含まれる。設定で「すべての文節」「しない」にも変えられる
- 1文節（「昨日は」など）入れて目を閉じると、それまでに確定した文を文脈として AI に送り、候補を最大5つ ← ↖ ↑ ↗ → に並べる（1番目が ←）。見て戻ると確定。確定した後に「戻す」（← 2秒 → ↗、または画面の「元に戻す」）と、確定を取り消して候補の画面にもどる（さらに目を2秒閉じると、入れた拍の入力画面へ）。一部だけ合っている時は、その候補を2秒見続けると文節が ← ↖ ↑ ↗ → に並ぶので、合っている文節を選ぶ（先頭の文節なら確定して残りを変換し直し、途中の文節ならその前後に区切りを入れて固定し、全体を変換し直す。固定した文節が違う候補は捨てる。それまでに見せた候補は違うと分かっているので、続きや全体の候補から除き、AI にも伝える）。区切りを入れずに変換した候補も、手元で文節に分ける（`src/phrases.ts`。辞書は使わず、表記の文字の種類と AI が返した読みから、助詞の後・ひらがなの後の漢字の前・名詞の後の動詞の前・「て」の後の動詞の前で区切る。明後日｜やろう、ゲームが｜したい、黙って｜やろう。漢字が続く所（明後日買おう）は切れない）。どれも違う時は目を閉じると、それまでに見せた候補を除いて、考える深さを1段上げて（low → medium）別の候補を聞き直す（「生卵が」のように文頭で出にくい言葉向け）。2秒閉じ続けると入力にもどる（入れた母音は残る）
- 区切りは文節ごと（「ね」を挟んで自然に切れるところ、主に助詞の後ろ）。例：昨日は｜楽しかったね｜ありがとう。区切った複数の文節をまとめて変換する時は、AI に「1区切りに自立語は1つまで（詰め込みは不可）、助詞の独立や複合語の分割など細かい区切りは可」と指示し（指示文 v4。単語ごとに なま｜たまご｜が と細かく区切ると当たりやすいことがあるため）、区切り位置まで入力と合う候補を先に並べる。1文節だけの時は v2（ラボの測定で、1文節に v3 を使うと候補が減った）。文頭の1文節は文脈が無く外れやすいので、少なくとも2回同時に聞いて候補を広げる
- → を2秒で文節の区切りを入れ、2文節以上をまとめて変換することもできる。後ろの文節が手がかりになるので、文脈の無い文頭の言葉（「生卵が 食べたい」の「生卵が」など）が当たりやすくなる
- 母音が入力と合わない候補は表示しない
- 設定で AI の会社・モデル・API キー・考える深さ・同時に聞く回数を選ぶ。既定は ChatGPT の GPT-6.1 Sol（考える深さ low・1回）。母音ラボの文単位の測定と実際の入力で最も当たりが良かった（Gemini 3.8 flash は3割ほど安いが、文頭の言葉を思いつけないことが多かった）。API キーはこのブラウザの中だけに保存し（母音ラボと共通）、選んだ会社の API に直接送る

### 英語

画面右上の「言語」で日本語と英語を切り替えます。5文字ずつアルファベット順に並べ、**a〜y は短い操作だけで、スペースは目を閉じるだけで**入ります（電話機式の ABC/DEF だと8グループ必要で、一部が2秒待ちの側に回るため）。この方式ではどのグループ・どの位置も手間が同じなので、使用頻度順に並べても速くならず、覚えやすいアルファベット順にしています。

| 1段目 | 短く | 長く（2秒） |
|---|---|---|
| ↖ | A B C D E | 1–5 |
| ↑ | F G H I J | 6–0 |
| ↗ | K L M N O | ! - : ; " |
| ← | P Q R S T | 編集（削除・Aa・読み上げ・元に戻す・Clear） |
| → | U V W X Y | ( ) / @ & |
| 目を閉じる／下を見る | スペース（0.6秒でその場で入力） | . , ? ' Z（そのまま2秒。入れたスペースは取り消す） |

- 2段目は日本語と同じく左から時計回り（A〜E なら ←A ↖B ↑C ↗D →E）
- 文頭の英字と、単独の「i」は自動で大文字。「Aa」で直前の文字の大文字・小文字を切り替え
- Backspace は「← を2秒、続けて ←」
- 読み上げは英語の声

画面のキーは 3×3 の正方形で並べています（横長だと斜めを見る時に視線が横に引っ張られるため）。中央は「見ても何も起きない」ことが分かるよう空けておき、目を閉じる（下を見る）操作は3段目の中央に置いています。

カメラなしでも、キーボードで流れを試せます。スマホではキーの中央に出る仮想スティックを使います（倒した向きがその方向、下に倒すと目を閉じる、離すと画面に視線を戻した扱い）。キーボードでは（`Q W E / A D` または矢印キーで方向、`Space`・`X`・`↓` で目を閉じる）。

### 入力ログ

どんな操作をして、どんな候補が出て、何を選んだかを時刻つきで記録する（使い勝手の確かめ用）。設定の「入力ログをコピー」かデバッグ欄のボタンで、設定の要約付きのテキストとしてコピーできる。このブラウザの中だけに最新 2000 件を保存し、設定で記録を止められる。母音入力では、入った母音と入力中の拍、変換で送った内容（文脈・最初の1文字・固定した文節・モデルと深さ・回数）、待ち時間、候補、はじいた候補の例、聞き直し、選んだ候補・文節を残す。

## 母音入力ラボ（実験）

`lab.html`（公開先では https://makkey.github.io/eye-board/lab.html ）は、日本語を**母音だけ＋文節の区切りの空白**で入力し（例：「昨日は 楽しかったね ありがとう」→「いおうあ あおいあっあえ あいあおう」）、LLM に元の文を推測させる方式の実験ページです。

- Claude / Gemini / ChatGPT を切り替え、API から取得したモデル一覧で比較できる（考える深さも選べる）
- API キーはブラウザの中だけに保存され、各社の API に直接送られる
- 例文（`src/lab/dataset.ts`、編集可）を「文単位」または「文節ごと（前の文節は確定済みとして次を推測）」で推測させ、正解が1位・5位以内に入った割合、母音が入力と合う候補の割合、時間を集計する
- 指示文は v1（規則のみ・5候補）、v3（v2 に「1区切り＝ちょうど1文節」の決まりを加え、区切り位置まで合う候補を先にする）、v4（v3 の決まりを「1区切りに自立語は1つまで・細かい区切りも可」に緩めたもの。本体の母音入力で複数の文節をまとめて変換する時に使う）と v2（例・自己確認つきで10候補を出させ、母音が合うものを上位に並べ替えて先頭5つで採点）を切り替えて比べられる。実際に送る内容はページ上で確認できる
- っ・ー の入れ方を3通りから選んで比べられる：両方そのまま、ローマ字入力のように っ は次の音の母音・ー は前の音の母音（とって→おええ、かーてん→ああえん）、っ はそのまま・ー は前の音の母音（本体の母音入力と同じ）
- 返答は毎回少しずつ違うため、同じ問いを2〜3回同時に聞き、候補の順位を合算することもできる（待ち時間はほぼ同じ、料金は回数倍）
- 結果はテキストでコピーできる（1問あたりの時間とトークン数も出す）
- ここで測った結果から、本体の母音入力の方式（文節ごとに文脈付きで聞く、1文節は v2・複数の文節は v4、文頭の最初の1文字は12キーで入れる、既定のモデルは GPT-6.1 Sol の low）を決めた

## 仕組み

- [MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker) で顔のランドマークと blendshape を取得（すべて端末内で処理）
- 特徴量: blendshape の `eyeLook*`（上下左右）と `eyeBlink*`、目頭・目尻を基準にした虹彩位置、目の開き（上下まぶたの距離）
- キャリブレーションで中央・5方向・「目を閉じる」「下を見る」のサンプルを集め（下を見たサンプルも「閉じる」として記録）、クラスごとの代表値（中央値）とばらつきから最近傍で分類（ヒステリシス付き）
- キャリブレーション後、各クラスを正しく判定できた割合をデバッグ表示で確認できる（結果はテキストでコピーできる）
- 「閉じる」との切り替えにはヒステリシスを掛けない（瞬間的な揺れはエンジンのデバウンスで吸収）。判定の寄り具合は設定の「閉じた判定の広さ」で調整できる
- 状態機械（`src/engine.ts`）が方向の時系列を行選択・文字選択に変換

| ファイル | 役割 |
|---|---|
| `src/tracker.ts` | カメラと MediaPipe、特徴量の抽出 |
| `src/classifier.ts` | キャリブレーションの作成と方向の分類 |
| `src/calibration.ts` | 音声案内付きのキャリブレーション手順 |
| `src/engine.ts` | 入力の状態機械 |
| `src/layout.ts` | 言語ごとのキー配置 |
| `src/kana.ts` / `src/english.ts` | 濁点・小文字などの変換、英語の自動大文字 |
| `src/main.ts` | UI |
| `src/inputlog.ts` | 入力ログ（このブラウザの中だけに保存し、コピーできる） |
| `src/vowelime.ts` | 母音入力の変換（文節と文脈・最初の1文字のヒントを AI に送り、候補を絞る） |
| `src/phrases.ts` | 変換候補を手元で文節に分ける（「一部を使う」用） |
| `src/lab/` | 母音入力ラボ（母音への変換、LLM への指示と採点、各社 API の呼び出し） |

## 開発

```sh
npm install
npm run dev      # http://localhost:5173
npm test
npm run build
```

カメラは HTTPS か localhost でのみ使えます。顔認識モデルは初回に Google のサーバーから読み込みます。

## デプロイ

`main` に push すると GitHub Actions で GitHub Pages に公開されます（リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください）。

## 調整のヒント

- **設定**から各時間・平滑化・中央の広さなどを変更できます
- **デバッグ**で特徴量の動き、各方向への距離、まばたき値を確認できます
- 判定が不安定な場合は、明るさ・カメラの高さを変えて再キャリブレーションしてください
