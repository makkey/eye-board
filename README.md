# EyeBoard

目を「スティック」のように大きく動かして、12キー配列でひらがなを入力するウェブアプリの MVP です。

一般的な視線入力は「画面のどこを見ているか」を推定しますが、小さな画面では目の動きが小さく、普通のカメラでは精度が出にくいという課題があります。EyeBoard は画面から視線を外すくらい大きく目を動かしてもらい、**「中央・上・右下…」の9方向だけ**を判定します。画面を見ていない間は音声と効果音で状態を伝えます。

## 操作

| 1段目（行を選ぶ） | | |
|---|---|---|
| ↖ あ | ↑ か（2秒: 編集） | ↗ さ |
| ← た | 目を閉じる: な | → は |
| ↙ ま（2秒: ゛゜小） | ↓ や（2秒: わ） | ↘ ら（2秒: 、。？！） |

1. その方向を約0.4秒見る → 行名が読み上げられる → **画面に視線を戻す**と確定。「な行」は**目を0.6秒閉じ続ける**（その時点で選ばれるので、開けるタイミングは問わない）
2. 2段目は**フラワー配置**（ATOK のフラワータッチと同じく、左から時計回り）：← あ段、↖ い段、↑ う段、↗ え段、→ お段。見て戻ると確定
3. 何も選ばずに戻る：2段目で**下（↙↓↘）を見て戻る**か**目を0.6秒閉じ続ける**。5秒何もしなくても戻る

特殊な行（← ↖ ↑ ↗ → の順）:

- **゛゜小**: 切り替え（は→ば→ぱ→は）、小、゛、゜（直前の文字に適用）
- **わ**: わ、を、ん、ー
- **、。？！**: 、 。 ？ ！
- **編集**: 削除、空白、読み上げ、元に戻す、全消去

カメラなしでも、キーボードで流れを試せます（`Q W E / A D / Z X C` または矢印キーで方向、`Space` で目を閉じる）。

## 仕組み

- [MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker) で顔のランドマークと blendshape を取得（すべて端末内で処理）
- 特徴量: blendshape の `eyeLook*`（上下左右）と `eyeBlink*`、目頭・目尻を基準にした虹彩位置、目の開き（上下まぶたの距離）
- キャリブレーションで9方向と「目を閉じた状態」のサンプルを集め、**「目を閉じる」も10番目のクラスとして**、クラスごとの代表値（中央値）とばらつきから最近傍で分類（ヒステリシス付き）。下を見た時のまぶたの下がり方と、閉じた時の違いを全ての特徴量で見分ける
- キャリブレーション後、各クラスを正しく判定できた割合をデバッグ表示で確認できる（結果はテキストでコピーできる）
- 閉じる途中のまぶたは「下」を通るので、「閉じる」との切り替えにはヒステリシスを掛けない。判定の寄り具合は設定の「閉じた判定の広さ」で調整できる
- 状態機械（`src/engine.ts`）が方向の時系列を行選択・文字選択に変換

| ファイル | 役割 |
|---|---|
| `src/tracker.ts` | カメラと MediaPipe、特徴量の抽出 |
| `src/classifier.ts` | キャリブレーションの作成と方向の分類 |
| `src/calibration.ts` | 音声案内付きのキャリブレーション手順 |
| `src/engine.ts` | 入力の状態機械 |
| `src/layout.ts` / `src/kana.ts` | キー配置、濁点・小文字などの変換 |
| `src/main.ts` | UI |

## 開発

```sh
npm install
npm run dev      # http://localhost:5173
npm test
npm run build
```

カメラは HTTPS か localhost でのみ使えます。顔認識モデルは初回に Google のサーバーから読み込みます。

## デプロイ

`main` に push すると GitHub Actions で GitHub Pages に公開されます（リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください）。

## 調整のヒント

- **設定**から各時間・平滑化・中央の広さなどを変更できます
- **デバッグ**で特徴量の動き、各方向への距離、まばたき値を確認できます
- 判定が不安定な場合は、明るさ・カメラの高さを変えて再キャリブレーションしてください
