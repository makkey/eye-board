これは何？

日本語を母音だけ（あいうえお・ん・っ・ー）と文節の区切りの空白で入力し、LLM に元の文を推測させる実験です。 例：「昨日は 楽しかったね ありがとう」→「いおうあ あおいあっあえ あいあおう」。

API キーはこのブラウザの中だけに保存され、選んだ会社（Anthropic / Google / OpenAI / SB Intuitions）の API に直接送られます。 実行すると API の利用料金がかかります。

1. モデル

Sarashina の API はブラウザから直接は呼べない（サーバー側から呼ぶ前提の）ため、手元の PC で小さな中継を動かして、その中継経由で送ります。 cors-proxy.mjs をダウンロードし、 Node.js（18 以上）が入った PC のターミナルで node cors-proxy.mjs を実行してください。 API キーはこのブラウザ → 手元の中継 → Sarashina と渡るだけで、中継は保存も表示もしません。

2. 試しに入力してみる

        

          実際に使う時と同じように母音を入れて、1で選んだモデルがどんな文を返すかを見ます。
          文節の区切りに空白を入れてください（例：「昨日は 楽しかったね」→「いおうあ あおいあっあえ」）。
          母音の代わりに、ひらがな・カタカナの読み（例：「きのうは たのしかったね」）を入れても、自動で母音に変換して送ります。

    3. 例文でまとめて測る
    
        
    
          用意した例文（正解の分かっている日常会話60文）を母音に変換して1文ずつモデルに送り、正解の文がどれだけ当たるかを自動で数えます。
          1で選んだモデルで「実行」を押すと、終わった時に「4. 結果」に1行増えます。モデルや方式を変えて何度か実行すると、結果の表に並んで比べられます。
        
    
        
      
          
    • 文単位：文全体の母音（例：いおうあ あおいあっあえ あいあおう）を一度に送り、文全体が当たるかを見ます。
      • 
          
    • 文節ごと：実際の入力に近い方式です。利用者が文節を1つずつ入力して候補から選んでいく流れを再現します。前の文節までは正しく選べたことにして、その表記（例：「昨日は」）を文脈として付け、次の1文節の母音（例：「あおいあああえ」）だけを推測させます。1文が文節の数だけの問い合わせになり、結果の表には「昨日は ＋ あおいあああえ」のように送った内容が出ます。
      • 
          
    • 1回の問い合わせに数秒〜数十秒かかり、そのたびに料金がかかります。まずは「先頭から 5 文」で試すのがおすすめです。

    トークン/問は1問あたりの平均（何回か聞いた時は全回の合計。出力には考えた分を含む）。各社の料金表の単価（100万トークンあたり）を掛けると費用の目安になります。
    
        
    1位・5位以内の割合は、エラーにならなかった問いの中で数えています。エラーになった分は「3.」の「エラーになった〜件だけやり直す」で後から埋められます（API キーを入れ替えてからでも構いません）。
